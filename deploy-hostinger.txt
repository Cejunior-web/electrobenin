## 🎯 ÉTAPE 4/5 - DÉPLOIEMENT HOSTINGER (15 MIN)

### A. Connexion hPanel

1. **Va sur:** https://hpanel.hostinger.com
2. **Login** avec ton compte Hostinger
3. Clique sur ton **hébergement actif**

### B. Option 1: File Manager (LE PLUS SIMPLE)

**Étapes détaillées:**

1. Dans hPanel, clique **"File Manager"**
2. Navigue vers **`/public_html/`**
3. **SUPPRIME** tout ce qui est dedans (sauf .htaccess si existe)
4. Clique bouton **"Upload"** (en haut)
5. **Sélectionne tes 7 fichiers:**
   - index.html
   - panier.html
   - suivi.html
   - style.css
   - script.js
   - manifest.json
   - .htaccess

6. **Attends** la fin de l'upload (barre verte 100%)
7. **Vérifie** que les fichiers sont bien là

### C. Option 2: FileZilla (Si File Manager bug)

**Installation FileZilla (si pas installé):**
- Télécharge: https://filezilla-project.org/download.php?type=client
- Installe (Next, Next, Finish)

**Configuration FileZilla:**

1. **Ouvre FileZilla**
2. **Infos FTP** (dans hPanel > onglet "FTP Accounts"):
```
   Hôte: ftp.TON-DOMAINE.com
   Nom d'utilisateur: TON_USER@TON-DOMAINE.com
   Mot de passe: [créé dans hPanel]
   Port: 21
```

3. **Connexion rapide:**
   - Entre les infos en haut
   - Clic "Connexion rapide"

4. **Upload:**
   - Panneau gauche: Navigue vers ton dossier local
   - Panneau droit: Va dans `/public_html/`
   - **Sélectionne** tes 7 fichiers à gauche
   - **Glisse-dépose** vers la droite
   - Attends transfert terminé
